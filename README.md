# NumberSnipe

**Play. Think. Connect.**

NumberSnipe is a lightweight web game delivered as an installable Progressive Web App. The public repository contains the production build used for browser and mobile-friendly access.

## Product goals

- Immediate browser access
- Mobile-first layout
- Installable PWA experience
- Minimal deployment footprint
- Fast static hosting

## Technology

- HTML
- CSS
- JavaScript
- PWA manifest
- GitHub Pages

## Delivery model

```text
Web application
      ↓
Production assets
      ↓
 PWA packaging
      ↓
 GitHub Pages
```

## Current status

The repository is the public deployment package for NumberSnipe. It includes the compiled application assets, manifest and icons required for the web/PWA experience.

## Portfolio context

NumberSnipe represents the game/product side of my work: experimenting with compact interactive experiences, mobile delivery and frictionless browser deployment.
